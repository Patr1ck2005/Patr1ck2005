# Visual guide / 功能图导览

[English overview](tools-overview.md) · [中文介绍](tools-overview.zh-CN.md) · [Three-minute video / 三分钟视频](demo/research-tools-tour.mp4) · [Video sources / 视频来源](demo/README.md)

All scientific examples below use independently generated synthetic inputs. Software frames retain their stated public version and source. Follow the project link for reproduction, licensing and limitations.

以下科学示例均使用独立生成的合成输入。软件画面保留公开版本与来源；复现、许可及限制以各项目说明为准。

| Result / 结果 | When to use it / 适用场景 | One question to understand / 可亲自讲透的问题 |
|---|---|---|
| [![Path tracking](https://raw.githubusercontent.com/Patr1ck2005/eigenmode-analysis/public-release/docs/assets/showcase/hero.png)](https://github.com/Patr1ck2005/eigenmode-analysis) | **Eigenmode Analysis** — reorder numerical candidates while retaining missing observations. 重排数值候选并保留缺失位置。 | How do continuity and feature scaling affect an assignment? 连续性假设和特征尺度如何改变分配？ |
| [![Audit](https://raw.githubusercontent.com/Patr1ck2005/campaign-data/public-release/docs/assets/showcase/hero.svg)](https://github.com/Patr1ck2005/campaign-data) | **Campaign Data** — inspect scan coverage and incompatible meshes before analysis. 分析前检查覆盖与不兼容网格。 | Why is a missing point different from a duplicate or a mesh conflict? 缺失、重复、网格冲突有什么区别？ |
| [![Plotting](https://raw.githubusercontent.com/Patr1ck2005/plot-foundation/public-release/docs/assets/showcase/hero.png)](https://github.com/Patr1ck2005/plot-foundation) | **Plot Foundation** — render arrays with explicit orientation, masks and exports. 明确数组方向、掩膜和导出。 | Why does an x-first array often need transposition for a renderer? x-first 数组为什么经常需要转置？ |
| [![Workflow](https://raw.githubusercontent.com/Patr1ck2005/plot-workflows/main/docs/assets/showcase/hero.png)](https://github.com/Patr1ck2005/plot-workflows) | **Plot Workflows** — reuse a dataset across band, Q and polarization views. 同一数据复用到能带、Q 与偏振视图。 | What should remain identical when the presentation profile changes? 改变展示样式时什么必须不变？ |
| [![Optics](https://raw.githubusercontent.com/Patr1ck2005/MyOptics/main/docs/showcase/gaussian-propagation.png)](https://github.com/Patr1ck2005/MyOptics) | **MyOptics** — explore generic scalar optical propagation. 探索通用标量光传播。 | When does the propagation approximation apply, and how can width or power detect an error? 近似何时适用，宽度或功率如何暴露错误？ |
| [![GDS](https://raw.githubusercontent.com/Patr1ck2005/gds-layout-kit/main/docs/showcase/layout-overview.png)](https://github.com/Patr1ck2005/gds-layout-kit) | **GDS Layout Kit** — generate parameterized layouts and matching previews. 生成参数化版图及对应预览。 | Which round-trip checks connect a preview to the exported GDS? 哪些回读检查能将预览与 GDS 联系起来？ |
| [![Waves](https://raw.githubusercontent.com/Patr1ck2005/EM-Flow/master/docs/showcase/two-source.png)](https://github.com/Patr1ck2005/EM-Flow) | **EM-Flow** — inspect an interactive scalar wave simulation. 观察互动标量波模拟。 | What determines the interference pattern and its physical interpretation? 干涉图样由什么决定，模型含义是什么？ |
| [![Spirefall](https://raw.githubusercontent.com/Patr1ck2005/spirefall/master/docs/showcase/match-public-baseline.jpg)](https://github.com/Patr1ck2005/spirefall) | **Spirefall** — inspect a separate browser multiplayer game. 查看独立的浏览器多人游戏。 | How do movement, vertical spaces and game state shape a match? 移动、垂直空间和游戏状态如何组织对局？ |
